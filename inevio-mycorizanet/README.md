# inevio-mycorizanet

МИКОРИЗАnet — живой overlay-организм.

Один overlay. Автономный выбор транспорта. Шесть биопринципов.

## Что делает

- **Адресация** — свой корень `.spore`, детерминированные ULA.
- **Мембрана** — антигены (свой/чужой) + потенциал.
- **Феромоны** — маршруты усиливаются успехом, затухают неудачей.
- **Симбиоз** — связь жива, пока выгодна обоим.
- **Кворум** — порог концентрации сигналов.
- **Осмос** — поток по градиенту нагрузки.
- **Транспорт** — автономный выбор (UDP, TCP, DNS, ICMP, HTTP).

## Установка

    pip install inevio-mycorizanet

## Быстрый старт

    from inevio_mycorizanet import create_overlay

    overlay = create_overlay('node-1', secret=b'secret')
    overlay.send('node-2', b'hello')
