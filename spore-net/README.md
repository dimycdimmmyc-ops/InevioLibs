# SPORE — живая сеть одним модулем

Встраиваемый модуль децентрализованной сети, построенный
на метафоре грибницы. Конвейер 9 звеньев, дыхание,
зимовка, многослойная память (матрёшка), 8 адаптеров
транспорта (Wi-Fi Direct, Bluetooth, LoRa, 5G RedCap и др.).

## Установка

    py -m pip install spore-1.2.0-py3-none-any.whl

## Быстрый старт

    from spore import SporeNode
    from spore.soil.socket import ПочваSocket

    почва = ПочваSocket('127.0.0.1', 9000)
    узел = SporeNode(почва, имя='МойУзел', направление='V')

    while True:
        узел.дышать()

## API

- дышать() — один цикл дыхания
- отправить(кому, данные) — доставить сок
- принять(ждать_сек) — принять сок
- найти_соседей() — discovery
- зимовать() — сохранить ядро
- пробудиться() — восстановить из ядра
- статус() — сводка состояния
- SporeNode.выбрать_почву([...]) — автовыбор почвы

## Адаптеры почвы

- ПочваSocket — UDP через localhost (работает всегда)
- ПочваWiFiDirect — Wi-Fi Direct через winrt
- ПочваBluetooth — BLE Mesh
- ПочваWiFiAware — Wi-Fi Aware (Android)
- ПочваLoRa — дальняя связь
- ПочваRedCap — 5G IoT
- ПочваNFC — сверхближняя
- ПочваRFID — радиочастотная
